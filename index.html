Project Scope

Literature Survey

Grounded in established educational psychology and AI research to support slow learners through technology.

📚

Slow Learner Education

Slow learners — defined as individuals with IQ in the 70–90 borderline range — require more time, repetition, and scaffolding to acquire knowledge. Muthiah (2015) demonstrated that activity-centred teaching approaches yielded measurable improvements. Husain & Adam (2020) found visual and kinaesthetic methods significantly improved comprehension and retention in this population.

🎮

Gamification in Learning

Deterding et al. (2011) defined gamification as applying game-design elements in non-game contexts to drive motivation and goal-directed behaviour. Research consistently shows that points, badges, leaderboards, and streak tracking significantly increase engagement. Kapp (2012) emphasised that gamification produces maximal benefit when mechanics align with learning objectives — a principle central to DiverseMind's adaptive design.

⚡

Micro-Learning Pedagogy

Hug (2005) characterised micro-learning as delivering content in short, discrete units targeting single learning objectives — directly reducing working memory demands. Mohammed (2019) demonstrated that micro-learning modules produced significantly higher completion rates and post-assessment scores than full-length content among students with learning difficulties, validating this approach for the target population.

🤖

ML in Educational Analytics

Baker & Yacef (2009) identified engagement prediction as one of the most practically valuable ML applications, establishing five key behavioural feature categories all represented in DiverseMind's model. Khosravi et al. (2020) found that platforms integrating personalisation, analytics, and gamification consistently outperformed single-feature systems in both engagement and academic performance outcomes.

Research Gap

What's Missing in Existing Solutions

Current educational platforms fail slow learners in four critical dimensions that this research directly addresses.

GAP 01

No Adaptive Gamification for Slow Learners

Existing platforms apply generic gamification mechanics — points, badges, leaderboards — uniformly regardless of learner engagement state. No existing system calibrates reward difficulty or challenge type to individual ML-predicted engagement scores.

GAP 02

Limited ML Engagement Prediction in K–12

Machine learning applications in education primarily target grade prediction or dropout detection in higher education. The specific engagement prediction challenges of slow learners in primary school — irregular patterns, sensitivity to difficulty spikes — remain largely unaddressed.

GAP 03

Absence of Intelligent Micro-Learning

Micro-learning platforms deliver content in fixed sequences without dynamic adjustment. No existing system automatically determines when to introduce new content, revisit prior material, or reduce difficulty based on real-time performance data for slow learners.

GAP 04

No Holistic Integrated Framework

Platforms implement gamification OR analytics OR personalisation in isolation. No unified system combines all four pillars — gamification, micro-learning, ML engagement prediction, and recommendation — within a single child-centric framework designed specifically for slow learners.

GAP 05

No Proactive Teacher Intervention Tools

Existing platforms offer reactive reporting dashboards. No system provides predictive, real-time teacher alerts based on ML-detected engagement risk that enable intervention before disengagement becomes entrenched dropout behaviour.

GAP 06

Cold-Start Personalisation Problem

Recommendation systems require accumulated behavioural data before providing meaningful personalisation. No existing platform uses an initial multi-dimensional assessment to profile learning style, generating personalised content pathways from the very first session.

Problem & Solution

Research Problem & Proposed Solution

Research Problem

How can a gamified, ML-powered web platform improve the engagement, motivation, and learning outcomes of slow learners through personalised micro-learning?

Slow learners face a persistent educational gap due to:

  • Traditional instruction calibrated for average-paced learners
  • No adaptive technological support in mainstream classrooms
  • Generic gamification that fails to sustain motivation over time
  • No early warning system for teacher intervention
  • Lack of personalised content pacing for individual cognitive needs
Proposed Solution

DiverseMind — A Unified Gamified Micro-Learning Platform with ML-Based Engagement Prediction

The system addresses all identified problems through:

  • 30-question adaptive assessment to profile each learner from session one
  • Micro-lessons (3–5 min) with mastery-gated adaptive sequencing
  • ML engagement prediction (Logistic Regression, accuracy 0.98, AUC 1.00)
  • Real-time teacher alerts when Days_Inactive exceeds 5 days
  • Personalised recommendation engine combining content-filtering + gamification incentives
  • 20+ badges, XP system, leaderboard, streak tracking, and daily challenges
Research Objectives

What We Set Out to Achieve

Five specific objectives operationalise the main research aim.

01

Identify Engagement Levels of Slow Learners

Detect learners at risk of disengagement using behavioural data including login frequency, quiz scores, game metrics, time spent, and days inactive — enabling early intervention via ML prediction.

02

Deliver Gamified Micro-Learning Activities

Provide adaptive lessons based on individual performance, pace, and difficulty level. Break content into focused 3–5 minute modules targeting single learning objectives to reduce cognitive overload.

03

Personalise Learning Paths Using Machine Learning

Recommend suitable lessons and adjust difficulty dynamically using the composite recommendation score: CF similarity + ML engagement score + gamification alignment incentives.

04

Implement Adaptive Gamification System

Develop XP rewards, 20+ achievement badges, competitive leaderboards, daily challenges, and streak tracking — all calibrated dynamically to individual engagement prediction scores.

05

Empower Teachers with Real-Time Monitoring

Provide educator dashboards with per-student engagement predictions, risk assessments, and intervention strategy recommendations. Trigger proactive alerts before disengagement escalates.

06

Conduct Comprehensive System Evaluation

Validate through unit testing, integration testing, and user acceptance testing. Assess ML model performance via precision, recall, F1-score, and AUC-ROC. Collect educator and student feedback on usability.

Methodology

System Design & Development Approach

Agile development lifecycle with four pedagogical design principles at its core.

🧠

Cognitive Load Management

3–5 min micro-lesson units, single-objective content, mastery-gated sequencing using rolling accuracy threshold τ = 0.70.

🏆

Motivational Scaffolding

XP rewards, badges, leaderboard, daily challenges, and streak multipliers — all dynamically calibrated to ML engagement predictions.

📊

Data-Driven Personalisation

Logistic Regression on 5 behavioural features. Composite recommendation score combining content-filtering, engagement state, and gamification alignment.

👩‍🏫

Teacher Empowerment

Real-time dashboards with engagement predictions, risk flags, and intervention recommendations. Proactive alerts before disengagement escalates.

System Components

Six Integrated Modules

Each module contributes a critical function to the unified platform ecosystem.

Assessment Module

30-Question Initial Assessment

  • 6 learning style categories with targeted questions
  • Automatic scoring and profile generation
  • 40+ personalised activity recommendations
  • Historical assessment tracking and exportable reports
  • Eliminates cold-start personalisation problem
Gamification Module

Adaptive Engagement & Rewards System

  • Activity-based XP accumulation with difficulty calibration
  • 20+ unlockable achievement badges for milestones
  • Competitive cohort leaderboard rankings
  • Personalised daily challenges based on learning style
  • Consecutive login streak rewards with XP multipliers
Learning Module

Micro-Learning Content Delivery

  • 3–5 minute focused micro-lesson units
  • Mastery-gated adaptive sequencing (τ = 0.70 threshold)
  • Embedded formative assessment after each unit
  • Review cycle triggered when performance falls below threshold
  • 40+ activities across curriculum domains
ML Analytics Module

Engagement Prediction Engine

  • Logistic Regression on 5 behavioural features
  • Accuracy: 0.98 · Precision: 0.99 · AUC: 1.00
  • Login_Streak: strongest positive predictor (β = +6.20)
  • Days_Inactive: dominant risk signal (β = −8.08)
  • Real-time inference with <100ms response time
Teacher Dashboard

Educator Monitoring & Intervention

  • Per-student engagement scores and risk levels
  • Real-time alerts when Days_Inactive > 5
  • Assessment control and content assignment tools
  • ML analytics with intervention strategy recommendations
  • Class-level and individual progress visualisations
Student Interface

Personalised Learning Portal

  • Personalised content dashboard based on ML recommendations
  • Interactive games and gamified lesson activities
  • Progress visibility with visual milestone tracking
  • Achievement gallery and badge collection display
  • Child-friendly UI optimised for K–12 age groups
